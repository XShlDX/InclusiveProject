Что такое CSS
и зачем он нужен?

CSS — язык, который превращает скучный HTML в красивый интерфейс. Без него все сайты выглядели бы как текстовые документы из 90-х.

🎨 CSS = внешний вид сайта

HTML описывает структуру страницы. CSS отвечает за внешний вид: цвета, шрифты, размеры, отступы, анимации. Вместе они создают всё, что ты видишь в браузере.

CSS расшифровывается как Cascading Style Sheets — каскадные таблицы стилей. Слово «каскадные» означает, что правила накладываются друг на друга, и побеждает самое специфичное.

🏠
Аналогия: если HTML — это кирпичи и стены дома, то CSS — это покраска, обои и расстановка мебели. Структура и внешний вид разделены намеренно.

📎 Три способа подключить CSS

  • Внешний файл — самый правильный: <link rel="stylesheet" href="style.css"> в <head>
  • Тег <style> — прямо в HTML-документе, подходит для небольших проектов
  • Атрибут style="" — инлайновые стили, только для исключений, не используй постоянно
CSS · Первые стили
/* Выбираем тег h1 и задаём ему стили */ h1 { color: #e8ff57; font-size: 2rem; font-weight: 900; } /* Выбираем по классу */ .card { background: #13161e; border-radius: 14px; padding: 24px; }

Селекторы
и каскад

Селектор — это «адрес» элемента, которому ты хочешь задать стили. Понимание селекторов = умение точно нацеливаться на нужные элементы.

🎯 Основные виды селекторов

  • Тег — p { } — применится ко всем параграфам
  • Класс — .card { } — к элементам с class="card"
  • ID — #header { } — к конкретному элементу с id="header"
  • Псевдокласс — a:hover { } — при наведении мышки
  • Комбинация — .card h2 { } — h2 внутри .card
CSS · Виды селекторов
/* Тег — специфичность 0-0-1 */ p { color: gray; } /* Класс — специфичность 0-1-0 */ .highlight { color: #e8ff57; } /* ID — специфичность 1-0-0 (самый сильный) */ #title { color: white; } /* Псевдокласс — hover, focus, active */ button:hover { background: #5dffb0; } /* Дочерний — p внутри .card */ .card p { font-size: 0.9rem; }

🌊 Что такое каскад?

Когда два правила конфликтуют, браузер определяет победителя по специфичности. Побеждает наиболее специфичный селектор. Если специфичность равна — побеждает то, что написано позже в файле.

Порядок силы: ID > класс / псевдокласс > тег

⚠️
Не злоупотребляй ID для стилей. ID слишком специфичен — потом трудно перезаписать. Используй классы для стилизации, а ID только для JavaScript и якорей.

Box Model
и Flexbox

Каждый элемент на странице — это прямоугольник. Понимание Box Model объясняет, почему элементы стоят там, где стоят. Flexbox — главный инструмент современной раскладки.

📦 Box Model: контент → padding → border → margin

Каждый HTML-элемент состоит из четырёх слоёв. Снаружи внутрь: margin (внешний отступ) → border (граница) → padding (внутренний отступ) → content (сам контент).

Визуальная модель Box Model
content
CSS · Box Model
.card { width: 300px; padding: 24px; /* внутренний отступ */ border: 1px solid #333; /* граница */ margin: 16px; /* внешний отступ */ /* ВАЖНО: с border-box width включает padding+border */ box-sizing: border-box; }

↔️ Flexbox — одномерная раскладка

Flexbox выстраивает элементы по одной оси (горизонтально или вертикально). Идеален для навбаров, карточек в строку, центрирования. Включается одной строкой: display: flex.

  • justify-content — выравнивание по главной оси (горизонтали)
  • align-items — выравнивание по поперечной оси (вертикали)
  • gap — расстояние между элементами
  • flex-wrap — перенос элементов на новую строку
Flexbox — justify-content: space-between

CSS · Flexbox навбар
.navbar { display: flex; justify-content: space-between; align-items: center; gap: 16px; padding: 0 32px; height: 64px; } /* Все дочерние элементы стали flex-элементами */ .navbar a { color: rgba(240,242,245,.6); text-decoration: none; transition: color .2s; } .navbar a:hover { color: #f0f2f5; }
