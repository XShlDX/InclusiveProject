Что такое
JavaScript?

JavaScript — язык программирования браузера. Если HTML — это скелет страницы, CSS — её внешность, то JS — это мозг: он делает страницы живыми и интерактивными.

🤔 Зачем нужен JS?

Без JS страницы были бы статичными документами. JavaScript позволяет:

  • Реагировать на действия пользователя — клики, ввод, прокрутку
  • Изменять содержимое страницы без перезагрузки
  • Отправлять запросы на сервер и получать данные (AJAX / fetch)
  • Создавать анимации, игры, интерфейсы любой сложности
💡
JS запускается прямо в браузере — никакой установки не нужно. Открой консоль DevTools (F12 → Console) и можешь сразу писать код. Попробуй: alert('Привет, мир!')

📋 Как подключить JS к странице?

Есть два способа: встроенный тег <script> и подключение внешнего файла. Второй способ — лучшая практика для любого реального проекта.

❌ Встроенный — только для экспериментов
<script> console.log('Привет из встроенного скрипта'); </script>
✅ Внешний файл — правильный способ
<!-- В конце <body>, перед </body> --> <script src="script.js" defer></script> // В файле script.js: console.log('Страница загружена!'); // defer — дождаться загрузки HTML перед запуском

Переменные
и типы данных

Переменные — это именованные контейнеры для данных. В современном JS используют const и let. Данные бывают разных типов — числа, строки, булевы значения и другие.

📦 const vs let vs var

  • const — значение нельзя переназначить. Используй по умолчанию.
  • let — значение можно менять. Используй когда нужно переназначение.
  • var — устаревший способ. Не используй в новом коде.
JavaScript · Объявление переменных
const name = 'Алексей'; // строка — нельзя переназначить const age = 25; // число const isStudent = true; // булево let score = 0; // можно менять score = 10; // переназначение — ок // name = 'Иван'; — ОШИБКА! const нельзя переназначить

JavaScript · Работа со строками и числами
const firstName = 'Анна'; const lastName = 'Иванова'; // Конкатенация (склейка строк) const full = firstName + ' ' + lastName; // → 'Анна Иванова' // Шаблонные строки (template literals) — современный способ const greeting = `Привет, ${firstName}!`; // → 'Привет, Анна!' // Арифметика const sum = 10 + 5; // 15 const diff = 10 - 5; // 5 const mult = 10 * 5; // 50 const div = 10 / 4; // 2.5
⚠️
Частая ошибка: смешивать типы. '5' + 3 даст '53' (строку!), а не 8. Перед арифметикой преобразуй строку в число: Number('5') + 3 === 8 или +('5') + 3 === 8.

Функции
и работа с DOM

Функции — блоки кода, которые можно вызывать многократно. DOM (Document Object Model) — это представление HTML-страницы в виде объектов, которые JS может читать и изменять.

⚙️ Функции: объявление и стрелочные

  • function declaration — классический синтаксис, доступен до объявления
  • arrow function (=>) — современный компактный синтаксис
  • Функции могут принимать параметры и возвращать значение через return
JavaScript · Функции
// Классическое объявление function greet(name) { return `Привет, ${name}!`; } console.log(greet('Мир')); // → 'Привет, Мир!' // Стрелочная функция const add = (a, b) => a + b; console.log(add(3, 4)); // → 7 // Функция с условием const isAdult = (age) => { if (age >= 18) return 'Совершеннолетний'; return 'Несовершеннолетний'; };

🌐 Работа с DOM

DOM — это дерево объектов, где каждый HTML-тег является узлом. JS получает доступ к элементам через document и умеет менять текст, стили, атрибуты и обрабатывать события.

Структура DOM-дерева
<body>
<h1 id="title"> Заголовок </h1>
<button id="btn"> Нажми меня </button>
</body>
JavaScript · Поиск элементов и обработка событий
// Найти элемент по ID const title = document.getElementById('title'); const btn = document.querySelector('#btn'); // Читать и менять содержимое console.log(title.textContent); // → 'Заголовок' title.textContent = 'Новый заголовок'; // Менять стиль title.style.color = '#f7df1e'; // Слушать клик btn.addEventListener('click', () => { title.textContent = 'Кнопка нажата!'; btn.style.background = '#f7df1e'; });
💡
querySelector vs getElementById: querySelector('#id') гибче — принимает любой CSS-селектор ('.class', 'div > p'). getElementById('id') быстрее, но только для ID. В современном коде чаще используют querySelector.
