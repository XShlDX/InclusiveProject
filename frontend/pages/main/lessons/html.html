Что такое
семантическая разметка?

Семантика — это смысл. Семантические теги говорят браузеру и поисковику, что именно находится на странице, а не просто как оно выглядит.

🤔 Зачем это нужно?

Без семантики весь контент можно обернуть в <div> — и страница будет выглядеть нормально. Но тогда:

  • Поисковики не поймут, что главное на странице — и снизят рейтинг в поиске
  • Скринридеры (для слабовидящих) не смогут правильно прочитать содержимое
  • Другим разработчикам будет сложно понять код
💡
Главное правило: спроси себя «Что это за контент?» — и выбери тег по смыслу. Шапка сайта — <header>, навигация — <nav>, статья — <article>.

📊 Семантика vs <div>

Посмотри на два варианта одного и того же меню:

❌ Плохо — только div
<div class="header"> <div class="nav"> <div>Главная</div> <div>О нас</div> </div> </div> <!-- Браузер понятия не имеет, что это шапка и меню -->
✅ Хорошо — семантика
<header> <nav> <a href="/">Главная</a> <a href="/about">О нас</a> </nav> </header> <!-- Сразу понятно: это шапка сайта с навигацией -->

Основные
семантические теги

HTML5 принёс нам набор тегов, которые описывают смысл блоков. Вот самые важные из них — те, что ты будешь использовать на каждом сайте.

🏗️ Теги структуры страницы

  • <header> — шапка страницы или раздела. Обычно содержит логотип, навигацию, заголовок.
  • <nav> — блок с навигационными ссылками. Может быть внутри header или отдельно.
  • <main> — главный контент страницы. На странице должен быть только один!
  • <footer> — подвал: копирайт, контакты, ссылки.
  • <aside> — боковая колонка, дополнительный контент, реклама.

📝 Теги контента

  • <article> — самостоятельный материал: пост в блоге, новость, карточка товара.
  • <section> — тематический раздел. Обязательно должен иметь заголовок.
  • <h1>–<h6> — заголовки. h1 — один на странице, самый важный.
  • <p> — параграф текста.
  • <figure> + <figcaption> — изображение с подписью.
  • <time> — дата или время с атрибутом datetime.
html · Статья в блоге
<article> <header> <h2>10 советов по CSS Grid</h2> <time datetime="2025-05-01">1 мая 2025</time> </header> <p>CSS Grid — мощный инструмент...</p> <figure> <img src="grid.png" alt="Схема Grid"/> <figcaption>Пример Grid-раскладки</figcaption> </figure> </article>
⚠️
Частая ошибка: использовать <section> вместо <div> просто чтобы добавить «семантику». Section нужен только когда у блока есть смысловой заголовок. Иначе используй обычный <div>.

1. Для чего используется тег <nav>?
А
Для создания навигационного блока со ссылками
Б
Для нового абзаца текста
В
Для изображений и медиа
2. Сколько тегов <main> должно быть на странице?
А
Сколько угодно, зависит от дизайна
Б
Ровно один — это главный контент страницы
В
Не меньше двух — для мобильной и десктопной версии
3. В чём разница между <article> и <section>?
А
Никакой разницы, они взаимозаменяемы
Б
article — самостоятельный материал; section — тематический раздел с заголовком
В
article только для текстов, section для любого контента
