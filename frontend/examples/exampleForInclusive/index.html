Горячие клавиши

Управляйте интерфейсом без мыши

  • Alt + 1 Главная страница
  • Alt + 2 Раздел возможностей
  • Alt + + Увеличить текст
  • Alt + − Уменьшить текст
  • Alt + C Высокий контраст
  • Alt + H Озвучивание при наведении
  • Alt + V Голосовое озвучивание
  • Tab Следующий элемент
  • Shift + Tab Предыдущий элемент

Возможности

Всё для комфортного взаимодействия

  • 🔊

    Голосовое озвучивание

    Синтез речи для любого текста на странице. Нажмите «Озвучить» или Alt+V.

  • 🔎

    Масштаб текста

    Размер шрифта от 14 до 28px без потери структуры. Управление через кнопки А+ и А−.

  • ◑

    Высокий контраст

    Чёрный фон, белый и жёлтый текст — максимальная читабельность для слабовидящих.

  • ⌨

    Клавиатурная навигация

    Полный доступ к любому элементу через Tab, Enter и горячие клавиши Alt.

  • ⇔

    Увеличенные отступы

    Межстрочный интервал и внутренние отступы увеличиваются для снижения нагрузки на восприятие.

  • ♿

    ARIA-разметка

    Полная совместимость со скринридерами NVDA, JAWS и VoiceOver. Все роли и метки заданы.
